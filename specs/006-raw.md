# 006 — Serviço raw (portas TCP cruas)

Status: aprovada
Depende de: 001, 008

## Contexto
Portas "estratégicas" para testar túneis CONNECT e proxies TCP: registra todos os bytes recebidos com o tempo de
cada leitura e responde conforme o modo da porta.

## Requisitos
- RF-01: escuta as portas de `FS_RAW_PORTS` (`porta:modo`), padrão:

| Porta | Modo padrão | Banner |
| --- | --- | --- |
| 7 | echo | — |
| 21 | banner | `220 finger-sniffer FTP ready\r\n` |
| 22 | banner | `SSH-2.0-finger-sniffer\r\n` |
| 25, 587 | banner | `220 finger-sniffer ESMTP ready\r\n` |
| 110 | banner | `+OK finger-sniffer POP3 ready\r\n` |
| 143 | banner | `* OK finger-sniffer IMAP ready\r\n` |
| 993 | tls-banner | TLS com nosso certificado, depois `* OK finger-sniffer IMAP ready\r\n` |

- RF-02: modos:
  - `echo`: devolve o que recebe;
  - `banner`: o servidor fala primeiro, logo após o accept; depois age como `sink`;
  - `sink`: só recebe;
  - `source`: manda N bytes (`n=` na linha PROBE, padrão 1 MiB) e fecha;
  - `tls-*`: termina TLS antes e aplica o modo dentro.
- RF-03: se os primeiros bytes do cliente forem TLS (`0x16 0x03`) em qualquer porta, termina TLS (análise da spec 008)
  e aplica o modo dentro do túnel.
- RF-04: primeira linha opcional `PROBE <id>[ mode=echo|banner|sink|source][ n=N]\r\n` associa o probe e troca o modo;
  a linha não é ecoada.
- RF-05: meio-fechamento: depois do FIN do cliente, o servidor ainda manda `half-close test\r\n` e então fecha;
  o registro mostra se chegou.
- RF-06: registra cada leitura com tempo (ns) e tamanho; bytes completos de cada sentido.
- RF-07: nunca fecha antes de `FS_IDLE_DEFAULT` sem atividade (exceto `source`).

## Interfaces e contratos
- Publica: `fs.v1.raw.session`, `fs.v1.raw.read`, `fs.v1.web.tls.client_hello` (reaproveita o schema TLS),
  `fs.v1.svc.heartbeat`. Ver [asyncapi.yaml](../eventbus/nats/asyncapi.yaml).

## Dados
Nada persistido localmente.

## Critérios de aceite
- [ ] `nc host 7` ecoa; `nc host 25` recebe o banner antes de enviar qualquer coisa.
- [ ] `PROBE abcdefgh mode=source n=1000\r\n` na porta 21 recebe exatamente 1000 bytes após o banner.
- [ ] `openssl s_client -connect host:993` completa TLS e recebe `* OK`.
- [ ] Meio-fechamento registrado com `half_close.server_sent_after_client_fin=true`.
